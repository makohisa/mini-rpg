# ミニRPG

HTML1ファイルで動く、ターン制RPGのプロトタイプ。

## 遊び方

`index.html` をブラウザで開くだけ。ビルド不要。

- 移動: 矢印キー / WASD（スマホは画面下のパッド）
- けってい: Z / Enter / Space
- キャンセル: X / Esc

村のむらおさに話しかけ、のはらでレベルを上げ、北の洞窟のボスを倒すとクリア。所要20〜30分。

## 中身

マップ探索 / NPC会話 / 宿屋・道具屋 / ランダムエンカウント / ターン制バトル / レベルアップ / 宝箱 / ボス / エンディング

## 改造するには

`index.html` の `<script>` 内、上のほうにデータがまとまっています。

| 場所 | 内容 |
|---|---|
| `MAPS` | マップ。1文字＝1マス（`.`草 `T`木 `W`水 `r`道 `#`壁 `D`扉 `$`宝箱 `B`ボス地点、`~VCE`はワープ） |
| `MAPS[x].npcs` | NPCの位置とセリフ |
| `MAPS[x].warps` | マップ間の移動先 |
| `ENEMY` | 敵のHP・攻撃・防御・経験値・見た目 |
| `LVUP` / `statsForLv()` | レベルアップに必要な経験値と、能力値の伸び |
| `playerAction()` | 戦闘コマンドの処理（魔法・道具の効果） |

マップは文字列を書き換えるだけで地形が変わります。行の長さは全部そろえてください。

## 分担のヒント
